# Datasheet

This folder store the datasheets that are only "visible" from the Firmware, ie. only the components that are accessible over a serial bus from the MCU.
Dedicated logic ICs aren't included, as they're considered as standard GPIO regarding to the MCU, with a specific logic equation.

For a full documentation access, please refer to the [EtherBenchProbe](https://github.com/lheywang/EtherBenchProbe) repo which include the whole Altium project, 
and therefore give access to all the documentations.
